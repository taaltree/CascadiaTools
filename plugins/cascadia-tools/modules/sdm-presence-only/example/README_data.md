# Example data: Pacific marten presence-only records (SIMULATED)

**These data are simulated.** No real marten records are included. They were
generated by the module's own simulator so that the true parameter values are
known and the estimates can be checked against them.

- Generator: `dev/sdm-presence-only/make_example.R`, which calls
  `module$simulate()` with seed **2025**. It then rescales coordinates to UTM
  metres, adds record metadata (seed 7) and drops a few camera occasions (seed 8).
- True values: `example/TRUTH.txt` (repeated below).

## The story

A carnivore biologist wants to know where Pacific martens (*Martes caurina*)
live in a 60 x 60 km block of the Oregon Cascades (UTM zone 10N). She has
**180 marten records** collected from 1995 to 2024. They come from
iNaturalist, ODFW incidental reports, trapper reports and museum specimens.
Nobody surveyed the block systematically, so the records are "presence-only":
they show where martens were seen, not where they were looked for and missed.

Most records come from near roads, because that is where people are. The
roads follow the valleys. So low ground is over-searched, and a naive
analysis would mistake "near a road" for "martens like low elevation". The
biologist has a distance-to-road layer and wants to correct for that.

In 2023 her team also ran 45 camera stations (4 two-week occasions each).
These are used only in the second, optional analysis
(`config_integrated.yaml`). The main worked example (`config.yaml`) uses the
presence-only records and the covariate grid.

## Design

| dimension | value |
|---|---|
| study region | 60 x 60 km = 3,600 km², 3,600 grid cells of 1 km² |
| marten records (in file) | 180 (expected count in the simulation: 160) |
| other-species records in file | 12 fisher (*Pekania pennanti*), filtered out by `species:` in the config |
| habitat covariates | forest cover (%), elevation (m) |
| sampling-bias covariate | distance to nearest road (km); 4 straight roads |
| habitat-bias confounding | elevation vs distance to road r = 0.67 (vs sqrt(distance) r = 0.69) |
| camera survey (integrated config only) | 45 stations x 4 occasions, 9 occasions missing (171 rows), 1 km² per station |

## Files and columns

### `presence_records.csv` (192 rows: 180 marten + 12 fisher)

| column | meaning |
|---|---|
| `record_id` | record identifier (MACA- = marten, PEPE- = fisher) |
| `species` | scientific name |
| `date` | date of the record (YYYY-MM-DD), 1995-02-21 to 2024-12-22 |
| `source` | iNaturalist (85), ODFW incidental report (44), trapper report (34), museum specimen (17) for martens |
| `easting`, `northing` | UTM zone 10N coordinates (m) |
| `coord_uncertainty_m` | stated location error, 10-500 m (all smaller than the 1 km cell) |

### `covariate_grid.csv` (3,600 rows, one per 1 km cell centre)

| column | meaning |
|---|---|
| `easting`, `northing` | cell centre, UTM zone 10N (m) |
| `forest_cover_pct` | forest cover, % (7.6-98.3, mean 57.4, SD 24.6) |
| `elevation_m` | elevation, m (718-2135, mean 1350, SD 280) |
| `dist_road_km` | distance to the nearest road, km (0-30, mean 7.2, SD 6.3) |

### `camera_survey.csv` (171 rows; used only by `config_integrated.yaml`)

| column | meaning |
|---|---|
| `station` | camera station id (CAM001-CAM045) |
| `easting`, `northing` | station location, UTM zone 10N (m) |
| `occasion` | two-week occasion, 1-4 (a missing row = camera not working) |
| `detected` | 1 = marten photographed on that occasion, 0 = not |

## TRUE values (simulated; per 1 SD of each covariate over the grid)

| parameter | true value | meaning |
|---|---|---|
| `intensity_beta_forest_cover_pct` | 0.9 | log intensity per SD of forest cover; x2.46 per SD (24.6 points), x1.44 per 10 points |
| `intensity_beta_elevation_m` | 0.4 | log intensity per SD of elevation; x1.49 per SD (280 m), x1.15 per 100 m |
| `bias_beta_dist_road_km` | -1.1 | log recording rate per SD of distance to road; x0.33 per SD (6.3 km) |
| `density_at_mean_covariates` | 0.4 per km² | sets the overall level; NOT estimable from presence-only data |
| `expected_total_abundance` | 2300 | integrated model only |
| `mean_occupancy_prob` | 0.391 | 1 km² plot; integrated model only |
| `detection_prob` | 0.45 | per camera occasion; integrated model only |

The simulator's elevation field was shifted by +450 m when written to the CSV,
to give realistic Cascades elevations. Because covariates are standardised over
the grid, the shift does not change any per-SD value.

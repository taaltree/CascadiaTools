# Example data: mule deer winter-range line-transect survey (SIMULATED)

**These data are simulated.** No real deer were counted. Because the data were
simulated, the true answers are known, so the analysis can be checked against them.
The data were generated by `dev/distance/make_example.R` with `set.seed(2025)`.
`dev/distance/si/example_truth.R` re-runs that script without writing anything,
checks that it reproduces these CSV files exactly, and writes every true value to
`results/distance/si/truth.json`.

## The story

A state wildlife agency wants to know how many mule deer use a 360 km2 winter range,
and whether deer concentrate where there is more shrub forage (sagebrush and
bitterbrush) and farther from the main highway. The range is managed as two units,
**north** and **south**, each 180 km2.

In January 2025 (13 January to 2 February), two observers (initials AB and JK) walked 36
north-south line transects. The lines were placed at random within the range and were
1.9 to 4.1 km long (115 km of line in total). For every group of deer seen, the observer
used a laser rangefinder and compass to record the perpendicular distance from the line
to the centre of the group, and counted the deer in the group. Shrub cover and distance
to the highway were taken from a GIS layer for each transect and for every 1 km2 cell of
the study area.

## Design dimensions

| item | value |

| line length | 1.89-4.10 km, mean 3.19 km, total 114.9 km |
| study area | 360 km2 (north 180, south 180) |
| detections | 146 deer groups (486 deer); 145 within the 400 m truncation distance |
| detections by unit | south 97, north 49 |
| detections by observer | JK 83 (23 lines), AB 63 (13 lines) |
| farthest distance | 461 m |
| group size | 1-9, mean 3.33 |
| shrub cover on transects | 13.9-45.4 % (study-area grid: 3-55 %) |
| distance to road on transects | 0-10.8 km |

## Files and columns

`deer_observations.csv`: one row per deer group detected (146 rows).

| column | meaning |
|---|---|
| `transect_id` | transect where the group was seen (MD01-MD36) |
| `date` | date the transect was walked (YYYY-MM-DD) |
| `observer` | observer initials (AB or JK) |
| `perp_distance_m` | perpendicular distance from the line to the group centre, metres |
| `group_size` | number of deer in the group |

`deer_transects.csv`: one row per transect, **including MD18 with no detections** (36 rows).

| column | meaning |
|---|---|
| `transect_id` | transect id |
| `stratum` | management unit: `north` or `south` |
| `length_km` | length of line walked, km |
| `shrub_cover_pct` | mean shrub cover along the transect, % |
| `road_dist_km` | distance from the transect to the highway, km |
| `x_km`, `y_km` | transect location (km, local grid) |
| `observer` | observer who walked the line |

`study_area_grid.csv`: one row per 1 km2 cell of the study area (360 rows), used to
predict density over the whole range and draw the map.

| column | meaning |
|---|---|
| `x`, `y` | cell centre (km, same local grid) |
| `area_km2` | cell area (1) |
| `stratum` | management unit |
| `shrub_cover_pct`, `road_dist_km` | the two habitat covariates for the cell |

`config.yaml` is the analysis set-up (truncation 400 m, chosen before fitting).
`config_mcds.yaml` is the same with observer as a detection covariate. `recovery.yaml`
is the planted-truth test at this design.

## How the data were generated (TRUE values, simulated)

- Expected **group** density in each 1 km2 cell:
  log D = log(3.0) + 0.45 z_shrub + 0.25 z_road, where z is the covariate standardised over
  the 360 grid cells (grid SD: shrub 9.0 %, road 3.06 km).
- Each transect has the density of the cell it lies in. Groups were placed uniformly out to
  600 m on each side of the line.
- Group size = 1 + Poisson(2.4), so the mean is 3.4 deer.
- Detection is half-normal, g(0) = 1. The scale is sigma = 165 m for observer AB and 135 m for
  observer JK. Group size does not affect detection.
- Distances are rounded to the nearest metre. There is no movement, heaping or measurement error.

| true quantity (simulated) | value |
|---|---|
| deer density, whole study area | **11.31 per km2** (3.33 groups per km2 x 3.4) |
| deer abundance, whole study area | **4,071** (1,197 groups) |
| density north / south | 8.43 / 14.19 per km2 |
| abundance north / south | 1,517 / 2,554 |
| mean group size | 3.4 |
| detection probability within 400 m (P_a) | 0.456 (effective strip half-width 182 m) |
| half-normal scale | 165 m (AB), 135 m (JK); a single sigma of 146 m gives the same P_a |
| shrub-cover effect | x1.65 per 10 % points of shrub cover (log slope 0.489 per transect SD of 9.78 %, rate ratio 1.63 per SD) |
| road-distance effect | x1.28 per 3 km farther from the road (log slope 0.223 per transect SD of 2.73 km, rate ratio 1.25 per SD) |
| density at a transect with average covariates | 10.37 deer per km2 (3.05 groups per km2) |

These are **expected** values. The simulation drew deer only inside the surveyed strips,
not over the whole study area, so there is no "realised" population total. The table in
`results/distance/si/truth.json` gives the values to more digits.

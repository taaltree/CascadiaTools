# Example data: Cuban and green treefrogs in PVC-pipe refugia

> **These data are SIMULATED.** They were generated by
> `dev/occu-waddle/make_example.R` (R, `set.seed(2010)`) to look like a real
> field data set. They are not field data. Because they are simulated, the
> true parameter values are known (bottom of this file), so the worked
> example can show whether the analysis gets the right answer.

## The system

The Cuban treefrog (*Osteopilus septentrionalis*) is an invasive, large
treefrog in southern Florida. It eats and competes with native treefrogs.
The green treefrog (*Hyla cinerea*) is a common native species. Both use
PVC pipes hammered into the ground or tied to trees as daytime refuges, so
pipe surveys are a standard way to monitor treefrogs (Waddle et al. 2010).

The Cuban treefrog is treated as the **dominant** species and the green
treefrog as the **subordinate** species. That ordering is a biological
assumption chosen before looking at the data (the invader is larger and
preys on native treefrogs), not something the analysis tests.

## The story of the (simulated) study

A crew placed a cluster of 10 PVC pipes at each of 180 sites spread over
wetlands and tree islands west of Miami (latitude 25.50-26.00 N, longitude
80.35-80.94 W). Each site was visited 5 times, about every 3 weeks, from
5 June to 31 August 2023. On each visit an observer checked all 10 pipes
and recorded whether each species was found in any pipe (1) or not (0),
and the air temperature. Some visits did not happen (flooded access,
staff shortage): 60 of the 900 planned visits are missing.

The question: **Is the green treefrog found at fewer sites where Cuban
treefrogs occur than where they do not, and is it harder to find green
treefrogs in the pipes on visits when Cuban treefrogs are in them?**

Cuban treefrogs spread along roads and disturbed areas, so the crew
recorded distance to the nearest road. Green treefrogs prefer shaded tree
islands, so they recorded canopy cover.

## Design

| dimension | value |
|---|---|
| sites | 180 |
| visits per site (planned) | 5 |
| visits done | 840 (126 sites with 5, 48 with 4, 6 with 3) |
| visits missed | 60 (6.7%) |
| site covariates | distance to road (29-5409 m, median 584), canopy cover (3-89%, median 48) |
| visit covariate | air temperature (17.8-32.9 C, mean 25.0) |
| detections (visits with the species found) | Cuban treefrog 226, green treefrog 209 |
| sites where each species was found at least once | Cuban 90, green 81, both 23 |

## Files and columns

### `pipe_surveys.csv` (one row per site x visit; 900 rows)

| column | meaning |
|---|---|
| `site_id` | site code, `WCA-001` to `WCA-180`; matches `sites.csv` |
| `visit` | visit number, 1-5 |
| `date` | date of the visit (YYYY-MM-DD) |
| `observer` | initials of the person who checked the pipes (JHW, KR, MS). Not used in the model; no observer effect was simulated |
| `air_temp_c` | air temperature at the visit, degrees C. Empty when the visit was not done |
| `pipes_checked` | number of pipes checked: 10 = visit done, 0 = visit not done |
| `cuban_treefrog` | 1 = at least one Cuban treefrog found in the pipes, 0 = none. Empty when the visit was not done |
| `green_treefrog` | 1 = at least one green treefrog found, 0 = none. Empty when the visit was not done |

### `sites.csv` (one row per site; 180 rows)

| column | meaning |
|---|---|
| `site_id` | site code |
| `dist_road_m` | distance from the pipe cluster to the nearest road, m |
| `canopy_pct` | canopy cover over the pipe cluster, % |
| `lat`, `lon` | site location (decimal degrees, WGS84). Not used in the model |

## TRUE parameter values (simulated)

The generator uses the conditional two-species occupancy model of the
module (Richmond et al. 2010; Waddle et al. 2010). Occupancy covariates are
standardised over the 180 sites; air temperature enters as
(temperature - 25) / 2.3 in the generator. Below, the truth is expressed on
the module's scale: probabilities at the average covariate value, slopes
on the logit scale per 1 standard deviation (SD) of the covariate (SD of
air temperature over the 840 done visits = 2.485 C). Computed by
`dev/occu-waddle/si_truth.R`, saved in `results/occu-waddle/si/truth.csv`.

| quantity | symbol | estimates-table name | TRUE value |
|---|---|---|---|
| Cuban treefrog occupancy | psiA | `occ_dominant` | 0.525 |
| ... slope per SD of log(distance to road) | | `occ_dominant_beta_log_dist_road_m` | -0.90 |
| Green treefrog occupancy where Cuban present | psiBA | `occ_sub_given_dom_present` | 0.250 |
| ... slope per SD of canopy cover | | `occ_sub_given_dom_present_beta_canopy_pct` | +0.60 |
| Green treefrog occupancy where Cuban absent | psiBa | `occ_sub_given_dom_absent` | 0.690 |
| ... slope per SD of canopy cover | | `occ_sub_given_dom_absent_beta_canopy_pct` | +0.50 |
| Cuban detection per visit, green absent | pA | `det_dominant_alone` | 0.550 |
| ... slope per SD of air temperature | | `det_dominant_alone_beta_air_temp_c` | +0.378 |
| Green detection per visit, Cuban absent | pB | `det_sub_alone` | 0.600 |
| ... slope per SD of air temperature | | `det_sub_alone_beta_air_temp_c` | +0.270 |
| Cuban detection per visit, both present | rA | `det_dominant_with_sub` | 0.55 |
| Green detection, both present, Cuban found that visit | rBA | `det_sub_with_dom_detected` | 0.30 |
| Green detection, both present, Cuban missed that visit | rBa | `det_sub_with_dom_missed` | 0.55 |

| Probability a site holds both | psiA x psiBA | `occ_both` | 0.131 |
| Species interaction factor (1 = independent) | SIF | `species_interaction_factor` | 0.544 |
| Occupancy log-odds ratio, green with vs without Cuban | | `occ_log_odds_ratio_sub` | -1.90 |
| Detection log-odds ratio, Cuban found vs missed | | `det_log_odds_ratio_sub` | -1.05 |

Realised (latent) states in this one simulated data set: Cuban treefrogs
truly occupied 93 sites, green treefrogs 88, both 29. The crew found Cuban
treefrogs at 90 sites, green treefrogs at 81 and both at 23, so 3, 7 and 6
occupied sites were missed.

In words: the truth is that green treefrogs are much less likely to occupy
a site where Cuban treefrogs live (0.25 vs 0.69), both species are more
common in some habitats (Cuban near roads, green under canopy), and green
treefrogs are harder to find in the pipes on visits when Cuban treefrogs
are found there (0.30 vs 0.55).

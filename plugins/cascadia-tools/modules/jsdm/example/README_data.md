# Example data: forest breeding birds in a Cascade Range landscape

> **These data are SIMULATED.** They were generated by `make_example.R` (seed `20261019`)
> from the HMSC model the jsdm module fits. They are for demonstration only. The species
> names and body masses are real; the stations, detections and "true" responses are not.
> Because the data are simulated, the true parameter values are known (listed below) and
> the estimates can be checked against them.

## The story

A field team surveyed breeding birds at 120 point-count stations in the western Cascades
in May-June 2025. The stations lie along 12 short transects (10 stations each) spread over
a landscape of about 25 x 18 km, from about 120 m to 1,980 m elevation. Each station was
visited 3 times, about two weeks apart. On each visit an observer recorded every species
detected and the number of individuals.

For each station the team has the UTM coordinates, the elevation, the July mean maximum
temperature (from a climate grid) and the canopy cover (%) measured at the plot.

The team wants to know:

1. How does each of the 15 common forest species respond to summer temperature and to canopy cover?
2. Does body size explain which species respond how (for example, do large species avoid warm sites)?
3. Which species occur together more, or less, often than their shared habitat predicts?
4. How does the expected number of species at a station change along the two gradients?

## Design

| dimension | value |
|---|---|
| sampling units (point-count stations) | 120 (12 transects x 10 stations) |
| visits per station | 3 (pooled to detected / not detected for the analysis) |
| species | 15 (14 passerines, 1 woodpecker) |
| site covariates | 2: July mean max. temperature (12.8-25.0 °C), canopy cover (5-98 %); correlation -0.27 |
| species trait | 1: body mass (6.1-77.6 g; log scale in the model) |
| taxonomy | order and family (used as a taxonomic tree) |
| response | presence/absence (probit link) |
| detection records | 1,446 rows |
| stations where a species was detected | 17 (Chestnut-backed Chickadee) to 89 (Varied Thrush) of 120 |

## Files and columns

### `bird_detections.csv` (one row per species detected on a visit)

| column | meaning |
|---|---|
| `station` | station id, `CAS-001` ... `CAS-120` (matches `stations.csv`) |
| `visit` | visit number, 1-3 |
| `date` | survey date (YYYY-MM-DD) |
| `species` | scientific name (matches `bird_traits.csv`) |
| `count` | number of individuals detected (>= 1) |

A station x species combination that does not appear is a non-detection. The module sums
the counts over visits and turns them into detected (1) / not detected (0).

### `stations.csv` (one row per station, including stations with no detections)

| column | meaning |
|---|---|
| `station` | station id |
| `utm_e`, `utm_n` | UTM easting and northing (m, zone 10N) |
| `elevation_m` | elevation (m); not used in the model (temperature is derived from it) |
| `july_temp_c` | July mean maximum temperature (°C) |
| `canopy_cover_pct` | canopy cover (%) |
| `survey_year` | 2025 for all stations |

### `bird_traits.csv` (one row per species)

| column | meaning |
|---|---|
| `species` | scientific name |
| `common` | common name (used as labels in the report and figures) |
| `family`, `order` | taxonomy |
| `body_mass_g` | typical adult body mass (g) |

## How the data were generated (TRUE values, SIMULATED)

Covariates and the trait are standardised (mean 0, SD 1). For station i and species j:

    liability L_ij = beta_0j + beta_1j * temp_i + beta_2j * canopy_i + eta_i1 * lambda_1j + eta_i2 * lambda_2j + e_ij
    occupied if L_ij > 0;   e_ij ~ N(0, 1);   eta ~ N(0, 1)  (2 latent "site factors")
    beta_kj = Gamma_k0 + Gamma_k1 * log(body mass)_j + N(0, 0.5^2) species deviation
    lambda_1j ~ N(0, 0.9^2),  lambda_2j ~ N(0, 0.6^2)

Then each occupied station x species was detected on each of 3 visits with probability 0.7
(so P(detected at least once | present) = 0.973), with 1 + Poisson(0.6) individuals per
detection. 14 of 678 occupied station x species combinations (2%) were never detected.

**True Gamma (trait model; conditional probit scale)**

| | community mean (average-mass species) | effect of +1 SD log body mass |
|---|---|---|
| intercept | -0.40 | +0.35 |
| July temperature (per SD) | +0.50 | -0.45 |
| canopy cover (per SD) | +0.40 | +0.30 |

Other generating values: species SD around the trait model 0.5; latent loading SD 0.9 and 0.6;
no spatial structure; no phylogenetic signal (rho = 0); no true effect of elevation beyond
temperature.

**True values of the quantities the report interprets** (this particular community of
15 species; `results/jsdm/si/truth_full.csv`)

| quantity | truth |
|---|---|
| community average population-averaged response to temperature (`comm_popavg_july_temp_c`) | 0.227 |
| community average population-averaged response to canopy (`comm_popavg_canopy_cover_pct`) | 0.257 |
| realised body-mass slope on prevalence (`popavg_trait_..._on_intercept`) | 0.327 |
| realised body-mass slope on temperature response | -0.223 |
| realised body-mass slope on canopy response | 0.245 |
| expected species richness at average temperature and canopy | 5.65 |
| latent residual correlations | 105 pairs, range -0.75 to 0.75; 62 pairs with abs(r) > 0.3 |

Per-species true Beta values are in `truth.csv`; per-species population-averaged responses,
prevalences and pairwise residual correlations are in `results/jsdm/si/truth_full.csv`.

## What the data do NOT contain

- No real survey data. Do not cite the estimates as biology.
- Detection was imperfect (0.7 per visit) but the module does not model detection. With
  3 visits this misses only 2% of occupied cells, so its effect here is small.
- Stations are clustered along transects, but the truth has no spatial autocorrelation.
